# ROBOT-DOT-COM (로봇닷컴)

로봇 회사를 떨어뜨리고 합쳐서 창업 → 시드투자 → 시리즈A … → 유니콘으로 키우고, 유니콘 둘을 합쳐 상장시키는 머지 게임. [Robot Rush](https://kimtaenim.github.io/robot-rush/)의 자매작.

판 위의 회사는 전부 가상이며, 실제 로봇 회사 40곳의 이야기는 카드(data/cards.json)와 도감으로만 등장.
