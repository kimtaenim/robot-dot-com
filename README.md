# ROBOT-DOT-COM (로봇닷컴)

로봇 회사를 세워 시장을 선점하고, 경쟁사와 닿으면 큰 쪽이 작은 쪽을 먹고, 매각 또는 상장한 뒤 재창업하는 헥사 증식 게임. [Robot Rush](https://kimtaenim.github.io/robot-rush/)의 자매작.

실존 기업과 무관한 교육용 게임. 판 위의 회사는 전부 가상이며, 실제 로봇 회사 40곳의 이야기는 사건 카드(data/cards.json)로만 등장.
